# Action format

Every action carries four things and nothing else.

| Field | Rule |
|---|---|
| Owner | One named person. Never a team, never "we". |
| Action | A verb the owner can start on Monday morning. |
| By | A date. "Soon" is not a date. |
| Because | The decision it came from, in the words used in the meeting. |

An item that cannot carry all four is not an action. It is a topic, and it goes
under "raised, not decided".

Never invent an owner. Where the meeting did not name one, the item goes under
"raised, not decided" with the sentence that left it open.
