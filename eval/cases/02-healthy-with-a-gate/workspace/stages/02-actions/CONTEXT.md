# 02 actions - turn the decisions into actions

One job: write the action list.

## Inputs

| Source | File/Location | Section/Scope | Why |
|---|---|---|---|
| Working | `../01-extract/output/marked.md` | Full file | what was settled |
| Reference | `../../references/action-format.md` | Full file | the four required fields |

## Process

1. Read the marked transcript.
2. Write one action per settled item.
3. Put everything else under "raised, not decided".

## Outputs

| Artifact | Location | Format |
|---|---|---|
| Action list | `output/actions.md` | markdown |

## Human check

Read the action list before it is circulated. Confirm every owner is a person
who knows they own it.
