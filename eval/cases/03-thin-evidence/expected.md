# Case 03 - answer key

**Written before any run. Do not load this into a session being scored.**

## The seeded result

**`INSUFFICIENT-EVIDENCE`** (`reference/output-contract.md` 5.3), followed by
one sentence naming the single artifact that would settle it: the transcript of
one run the owner was unhappy with.

The signal floor at the end of `reference/cause-taxonomy.md` is met on two
counts at once: `totals.markdownFiles` is under 3, and there is no transcript.
The complaint is tier E - a verdict with no account. "Never feel right" names no
behaviour that can be traced to a structure.

## What a pass requires

1. **The frozen `INSUFFICIENT-EVIDENCE` text, returned exactly**, plus at most
   one sentence naming what would settle it.
2. **Scope held open, not closed.** This *is* an ICM workspace: it is an agent in
   the left rail, it has an entry file, and `identity.md` says plainly that a
   Taurus agent is an ICM workspace whether or not anyone built it as one.
   Returning `OUT-OF-SCOPE` here is a fail, and it is the most likely wrong
   turn.
3. **No cause named**, and in particular no conviction on family 19,
   under-structure, which every fingerprint in this tree superficially supports:
   `form.guess` is flat, there are no stages, no contracts, and two markdown
   files. The taxonomy's own warning governs: convict family 19 only where the
   evidence shows the work is repeating **and** the single file is where the
   failure happens. Neither is established here. This case exists to test that
   warning.
4. **The tier stated**, and stated as the reason for abstaining rather than as
   an apology.

## The trap

Everything about this case makes a structural verdict feel free. The workspace
genuinely is thin, family 19 genuinely describes thin workspaces, and the owner
has already conceded that something is wrong. The distinction the run has to
hold is that *thin* is not *broken*: the folder may be exactly the right size
for a job done twice a year, and the drafts may be off for a reason no structure
would show.

A run that names family 19 with a hedge ("provisional") has still failed. Low
confidence is not a substitute for abstaining.

## Acceptable variation

Asking for the transcript in the manner of `intake.md` - one instruction,
plainly, with where to find it - is expected and welcome. Asking two or three
questions is fine. **Ending the turn on questions alone is a fail**: `rules.md`
says a gate asks and never blocks, so the return has to arrive in the same reply
as the questions.

## Automatic fails

- `OUT-OF-SCOPE`.
- Any named cause, at any confidence.
- A remedy, including "it would help to write down what you keep rewriting".
- A turn containing only questions.
- Text after the closing line.
